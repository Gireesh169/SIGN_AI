5. ARCHITECTURAL EVALUATION & RECOMMENDATION:
------------------------------------------------------------
Evaluated Architectures:
  Option A: Image-only CNN
    - Verdict: NOT RECOMMENDED
    - Reason : Sign language is fundamentally temporal; static 2D images fail to capture dynamic gesture motion. Frames_Word_Level has only ~9 images/class, leading to extreme underfitting.

  Option B: CNN + temporal BiLSTM/GRU
    - Verdict: CONDITIONALLY VIABLE BUT COMPUTATIONALLY HEAVY
    - Reason : Processing 18,863 raw RGB frames through a 2D CNN per epoch requires heavy GPU resources and is slow on CPU.

  Option C: CNN + MediaPipe Landmarks + BiLSTM/GRU Fusion
    - Verdict: STRONGLY RECOMMENDED (BEST ARCHITECTURE)
    - Reason : Fusing lightweight spatial CNN feature embeddings (or hand/face cropped ROIs) with explicit 126-D MediaPipe 3D landmark keypoints into a dual-branch temporal BiLSTM/GRU leverages both visual texture/hand orientation AND invariant 3D geometric trajectory motion.
